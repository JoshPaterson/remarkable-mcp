# Fonts

Single-stroke fonts for erasable text marks (text written as tablet ink).

- `EMSReadability.svg`, `EMSReadabilityItalic.svg`: EMS Readability by
  Sheldon B. Michaels, a single-stroke derivative of Source Sans Pro Light
  (Paul D. Hunt, Adobe); SVG font conversion by Windell H. Oskay. From the
  Inkscape extensions repository (`svg_fonts/`). Licensed under the SIL Open
  Font License 1.1 (`OFL-EMS-Readability.txt`).
